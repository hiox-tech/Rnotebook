# 快速开始

**新建笔记 → 写作 → 运行 R → 导出报告**

## 先准备

⌘N 新建，⌘S 命名为 `.qmd` 或 `.Rmd`。在 **设置 → 环境** 确认 Rscript、Quarto 与所需 R 包；只写笔记时可直接开始。

## 第一份可运行笔记

切到 Code，复制示例；切到 Visual 查看排版。光标放入 R 块，按 ⌘↩，结果为 **18**，变量区出现 `x`。

````markdown
---
title: "第一份笔记"
format: html
---

# 测量

```{r}
x <- c(12, 18, 24)
mean(x)
```
````

## 常用操作

| 要做什么 | 操作 |
| --- | --- |
| 写作与阅读 | Code 编辑原文；Visual 使用格式工具与大纲 |
| 查找与替换 | ⌘F 查找；展开替换；箭头跳到上／下一处 |
| 运行与中断 | ⌘↩ 当前 R 块；⇧⌘↩ 全部；⌘. 中断 |
| 整理 R 代码 | 块边格式化按钮；设置 → 格式化调整样式 |
| 查看变量 | 右侧筛选、预览；“载入更多”浏览后续对象 |

## 输出与分享

⇧⌘E 打开渲染：选格式、位置与参数来源，再导出。**HTML** 便于分享，**Word** 便于协作，**Typst PDF** 适合排版；LaTeX PDF 需要相应 TeX 环境。渲染会按文稿设置重新计算，不读取交互结果。

## 记住这三点

- 已命名笔记默认自动保存；外部修改可合并，冲突时先比对。
- R 对象属于当前会话；“保存 R 工作区”另存 `.RData`。停止或重启会清除变量。
- 数据、图片仍是普通文件。用相对路径引用，分享时一并提供；重开笔记不自动运行 R 或恢复旧结果。
