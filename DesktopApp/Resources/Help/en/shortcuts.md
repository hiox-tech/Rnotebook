# Keyboard Shortcuts

These are the main shortcuts in the app menus. ⌘ means Command, ⇧ Shift, ⌥ Option and ⌃ Control. Editing and execution commands target the active document. Help articles support Find but do not edit documents or run code.

## Documents and windows

| Action | Shortcut |
| --- | --- |
| New / Open | ⌘N / ⌘O |
| Save / Save As | ⌘S / ⇧⌘S |
| Close current window | ⌘W |
| Settings | ⌘, |
| Minimize | ⌘M |
| Full Screen | ⌃⌘F |

## Editing and Find

| Action | Shortcut |
| --- | --- |
| Undo / Redo | ⌘Z / ⇧⌘Z |
| Bold / Italic / Underline | ⌘B / ⌘I / ⌘U |
| Insert Link | ⌘K |
| Body / Heading 1–6 | ⌥⌘0 / ⌥⌘1–6 |
| Code / Visual | ⌃⌘1 / ⌃⌘2 |
| Find / Replace | ⌘F / ⌥⌘F |
| Next / Previous Match | ⌘G / ⇧⌘G |
| Use Selection for Find | ⌘E |
| Increase / Decrease / Reset Size | ⌘+ / ⌘− / ⌘0 |
| Request R Completion | ⌃Space |
| Format Current R Chunk | ⇧⌘I |

## Running and rendering

| Action | Shortcut |
| --- | --- |
| Run Current Chunk | ⌘↩ |
| Run Selected Code | ⌥⌘↩ |
| Run All Chunks | ⇧⌘↩ |
| Interrupt Run | ⌘. |
| Render with Quarto | ⇧⌘E |
| Open Rnotebook Help | ⇧⌘/ |

These are app defaults. System shortcuts or keyboard layouts can affect how they are entered. Check the menus for available commands. Stopping/restarting the whole R session is different from interrupting the current run.
