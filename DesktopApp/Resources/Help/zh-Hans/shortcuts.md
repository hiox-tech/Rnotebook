# 快捷键速查

以下为应用菜单提供的主要快捷键。⌘ 表示 Command，⇧ 表示 Shift，⌥ 表示 Option，⌃ 表示 Control。编辑与运行命令作用于当前活动文档；帮助阅读页支持查找，不能编辑或运行代码。

## 文档与窗口

| 操作 | 快捷键 |
| --- | --- |
| 新建 / 打开 | ⌘N / ⌘O |
| 保存 / 另存为 | ⌘S / ⇧⌘S |
| 关闭当前窗口 | ⌘W |
| 设置 | ⌘, |
| 最小化 | ⌘M |
| 全屏 | ⌃⌘F |

## 编辑与查找

| 操作 | 快捷键 |
| --- | --- |
| 撤销 / 重做 | ⌘Z / ⇧⌘Z |
| 加粗 / 斜体 / 下划线 | ⌘B / ⌘I / ⌘U |
| 插入链接 | ⌘K |
| 正文 / 标题 1–6 | ⌥⌘0 / ⌥⌘1–6 |
| Code / Visual | ⌃⌘1 / ⌃⌘2 |
| 查找 / 替换 | ⌘F / ⌥⌘F |
| 下一个 / 上一个匹配 | ⌘G / ⇧⌘G |
| 用选中内容查找 | ⌘E |
| 放大 / 缩小 / 默认字号 | ⌘+ / ⌘− / ⌘0 |
| 请求 R 补全 | ⌃Space |
| 格式化当前 R 块 | ⇧⌘I |

## 运行与导出

| 操作 | 快捷键 |
| --- | --- |
| 运行当前块 | ⌘↩ |
| 运行选中代码 | ⌥⌘↩ |
| 运行全部块 | ⇧⌘↩ |
| 中断当前运行 | ⌘. |
| Quarto 渲染导出 | ⇧⌘E |
| 打开 Rnotebook 帮助 | ⇧⌘/ |

这些是应用默认值，系统快捷键或键盘布局可能影响输入方式。需要确认当前可用入口时查看菜单。停止/重启整个 R 会话不等同于中断当前代码。
