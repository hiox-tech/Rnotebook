# 编辑与资源

Code 与 Visual 编辑同一份原文。先选择适合当前内容的视图，再用工具栏和菜单完成编辑。

## Code 与 Visual

Code 适合 YAML、长代码和精确标记；Visual 适合排版文字、浏览图片/公式/图形及使用格式工具。格式菜单与编辑工具始终可用，是否适合当前内容由你判断；执行操作后可用撤销恢复。

切换视图不会运行 R。两个视图可分别设置字体和字号，Code 还可设置高亮主题。

## 折叠和导航

Code 左侧行号旁的箭头可折叠代码围栏或标题下的章节；“视图”菜单提供折叠当前区域、所有代码块、所有章节和展开全部。折叠只改变显示，保存、复制和运行仍使用完整原文。切到 Visual 会展开显示，返回 Code 后保留当前窗口的折叠状态。

Visual 右侧是紧凑的标题文字导航，位于 Code 缩略概览对应的位置。点击标题跳转，箭头展开或收起子标题；当前位置以淡色标示。编辑工具栏以正文宽度居中。

## 格式和插入

使用“格式”调整标题、粗斜体、下划线、高亮、列表、引用等；使用“插入”添加链接、图片、表格、R/普通代码块、公式和 Mermaid。工具栏会根据宽度把部分入口放进更多菜单。

可以先在空白行选择标题级别再输入。格式化会改变 Markdown 原文；需要检查具体标记时切到 Code。

## R 代码补全与格式化

在完整的 R 代码块中按 Control-Space 请求补全。设置→补全可关闭代码补全。候选用于编辑，不会因此运行代码。

按 ⇧⌘I、“编辑 → 格式化 R 代码块”或块旁格式化按钮，格式化当前完整 R 块。该操作不启动 R，通常可一次撤销。先完成输入法组合文字再执行。

## 查找与字号

⌘F 打开当前文档查找，⌥⌘F 打开替换，⌘G / ⇧⌘G 查找下一个/上一个。工具栏放大镜也是查找入口。查找以正文下方的悬浮栏显示，不覆盖右侧导航；开启“替换”向上展开第二行，支持替换当前结果、全部替换、区分大小写和完整词语。只高亮匹配文字，保留正文配色。跳到折叠区域中的结果时会自动展开。

“视图”菜单可放大、缩小和恢复默认字号，作用于当前编辑模式。设置中的 Code/Visual 字体与字号保持独立。

## 图片、数据和路径

图片可以导入或写为普通链接；应用不自动把外部图片、数据和其他依赖归档到项目中。用相对路径组织附件，例如 `images/plot.png` 和 `data/input.csv`。

另存到不同文件夹时要自行维护引用文件。R 默认在文档目录中执行；如果代码调用过 `setwd()`，可用 `getwd()` 确认实际目录。

更多例子见[Quarto语法](rnotebook-help://article/syntax)。

R 格式化在“设置 → 格式化”选择跟随文稿附近的 `air.toml`，或自定义行宽、缩进与保留多行调用。块边按钮直接修改代码，不把阅读光标移入代码块。

## 高亮与补全偏好

设置的字体、高亮、补全、格式化均可从顶部直接进入。高亮提供默认、海洋、森林、暖色四套浅深色配色，可关闭语法颜色或强调注释斜体、关键字加粗；Code 外观始终跟随界面浅深色。配色用于 Code 和 Visual 代码块，不改文稿原文。

补全可调自动弹出、延迟、最少字符数和候选上限，并分别选择参数名、函数签名、当前 R 会话对象。关闭自动弹出后仍可用 Control-Space；可关闭 Return 确认以保留换行，Tab 仍可确认，Esc 关闭列表。读取当前会话对象不启动 R，也不执行文稿。
