User Guide

Meet Rnotebook

Rnotebook is a macOS notebook editor for R analysis and report writing. Keep explanations, calculations and report settings in a .qmd or .rmd file, run R beside your text, then use Quarto to create an HTML, Word or PDF report.

What to use it for

  • Analysis notes: keep data sources, cleaning steps, calculations and conclusions together.
  • Teaching and research: combine formulas, tables, figures and explanations, checking results as you write.
  • Recurring reports: express data loading, analysis and plotting as code, then render again when data changes.
  • Lightweight writing: edit Markdown, images and formulas without starting R.

Documents, sessions and reports

A document stores Markdown source, R code and YAML. An R session holds objects and interactive results created in this window. A report is a separate file generated by Quarto from the document. Saving the document does not store R memory or interactive outputs in its source. Run the code again to recreate results after reopening.

Images, CSV data and bibliographies remain ordinary files. If report.qmd refers to data/measurements.csv, preserve that relationship when sharing. The workspace has an editor and a right-hand inspector. Each document has an independent window and R session.
