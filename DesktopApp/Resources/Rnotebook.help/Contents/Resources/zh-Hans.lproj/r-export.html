R 运行与报告导出

交互运行用于探索，Quarto 渲染用于生成报告。两者都使用文档代码，但会话与执行上下文不同。

运行范围

操作入口
当前 R 代码块⌘↩，或块旁运行按钮
选中的代码⌥⌘↩
全部 R 代码块⇧⌘↩
当前位置以上或以下的块笔记本菜单/运行菜单
中断正在运行的代码⌘.，或运行中的停止按钮

围栏需要完整，光标／选区需要落在可运行的 R 内容中。以上／以下按当前位置确定范围。支持常见 RMD 块头，例如 {r setup, include=FALSE}，以及 Quarto 容器中的普通 R 块。公式、闭合 HTML 和长围栏示例不再禁用文档中其他明确的 R 块；示例里的代码不会运行。

列表／引用中的复杂嵌套围栏、无法明确映射的 HTML 内嵌 Markdown 仍不支持交互运行。未闭合区域可能影响到文末；其他位置明确的块可以单独运行，批量执行则先检查整个请求范围。

批量与手动运行

运行全部／以上／以下遵守静态布尔 eval：#| eval: false 或 RMD eval=FALSE 的块会跳过。运行当前块、块旁按钮和运行选区属于手动执行，仍会执行明确指定的原文，并在禁用 eval 时给出状态提示。全部块都跳过时，不启动 R，也不要求为未命名笔记选择保存位置。

默认在首个错误停止。块设置 #| error: true 或 error=TRUE 时，普通运行时错误后可继续同块后续表达式及后续块；失败仍记为失败。选区执行始终首错停止。中断、进程断连、资源限制等故障始终停止，不能被 error: true 覆盖。

批量结束后，悬停右侧 R 状态图标或版本号可查看成功、跳过、失败及未运行数量。跳过的块显示“本次已跳过”，旧结果原样保留，不算本次成功。

支持的执行选项

交互批量运行读取文档 YAML 的 knitr.opts_chunk、execute，再由块头和块顶部 #| 选项覆盖。execute.enabled: false 禁用整个批次，块级 eval 不能重新开启；明确的手动执行仍可用。支持常见块式和单行映射、注释及引号标量。标签必须唯一且符合支持的格式。

只静态解释布尔 eval/error；不执行参数表达式。表达式编号向量、YAML 标签／别名／继承、外部 metadata、child/code/ref.label 等代码替换机制不能静默变成普通运行，遇到相关不支持配置会在批量开始前提示。动态 knitr::opts_chunk$set() 不决定应用内调度。完整语义请使用 Quarto 渲染；不自动扫描项目配置。

echo、include、warning、message、图形参数和 cache/freeze 的渲染效果由 Quarto 处理。应用内保留调试输出，include: false 不表示跳过代码。

会话与变量

每份文档使用独立 R 会话。右侧电源启动/停止，旁边按钮重启；停止、重启会清除变量，先确认。中断当前运行和停止整个会话是不同操作。

变量可只读预览，list 可逐级展开，大对象按需加载。清空变量同样需要确认。“保存 R 工作区…”显式保存 RData，保存笔记正文不等于保存内存。重新打开笔记不自动恢复历史输出或执行代码。

工作目录默认是笔记文件夹；R 代码中可用 getwd() 查看。更换 R 或包库后按提示重启会话。

“笔记本 → 重启 R 并运行全部…”从干净会话检查文档，先确认清除变量；取消不执行，确认后按当前正文和批量选项重新准备任务。

包与 R 帮助

在检查器安装页选择 CRAN 镜像，搜索并选中包，再明确点击安装；也可选择本地安装包。安装目录来自环境设置。

右侧帮助搜索直接打开官方 R 搜索结果，不要求先启动 R 或保存笔记。“帮助”菜单继续保留 R 官方帮助、Quarto 和 QMD 官方语法网页。

导出设置

使用 Quarto 工具栏按钮或 ⇧⌘E。选择 HTML、Word、PDF/LaTeX 或 PDF/Typst，指定保存位置，可选择完成后打开。

参数来源默认为文档 YAML。切到自定义后按组调整文档、样式、代码与图形等参数；切回 YAML 时，隐藏的自定义草稿不会影响渲染，也不会被写回笔记。

自定义 HTML 使用主题及本地可用字体回退，不自动下载主题的网络字体，以免单文件资源嵌入阶段等待外部服务。YAML 模式继续遵守文档样式；用户自己引用的远程图片、字体或其他资源仍可能需要网络。

可复现与失败处理

导出在独立执行上下文中重新运行代码，不直接携带交互会话中的对象。将读取数据、加载包与对象创建写进笔记，并检查相对路径。

需要 TeX 的 PDF 引擎应先正确安装并配置；应用不自动安装 TeX。遇到缺包、代码错误或输出失败，在导出面板查看日志，按实际错误处理。取消或失败时不会把未完成结果当作正式成功输出。

Edmund 兼容转换的范围见Quarto语法。完整参数请看 Quarto 使用指南。

结果与变量的阅读

运行全部/以上/以下将本轮结果暂存，在整轮结束或中断后统一显示已执行内容。未执行的旧结果保留，不当作本次成功；单块手动运行仍即时输出。R 状态前的扇形以处理块数显示进度。

变量列表每批载入最多 500 条，底部“载入更多”可浏览剩余对象；筛选名称、类型与摘要时搜索完整会话元信息，而不只搜索已载入行。R 忙时筛选等待本次运行完成。对象预览只读，清空变量会先要求确认。
